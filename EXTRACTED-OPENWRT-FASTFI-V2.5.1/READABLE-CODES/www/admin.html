GCash E-Payment

Let customers pay with GCash — no coins, no gateway, no fees. Generate a pool of voucher codes here (one batch per coin rate), export them to a file, and import that file into the companion Android app. The app runs on the operator's phone: when a GCash "received ₱X" notification matching a rate price arrives, it pops one code from that rate's pool and SMSes it to the customer, who types it into the portal's "Wifi Pass" box. The app never needs to reach the router, so it works whether or not the operator's phone is on the router's network.

How It Works
  • Slot 1 (FREE): One Sub Vendo slot is free per router
  • Additional Slots: Requires license key
  • License binds to Router: License works only on parent license (locked to router license)

  • Same Router Only: License cannot be transferred to different router license
